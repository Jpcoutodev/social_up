# 🛠 Engineering & Design Standards

## 1. Stack Tecnológica Fixa
- **Core:** React.js (Vite)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Architecture:** Component-Based Modular Design

## 2. Padrões de UI/UX (High-End)
O resultado visual deve seguir a estética "Modern Luxury / Tech-Forward":
- **Tipografia:** Contraste entre fontes Display para títulos e Sans-serif monoespaçadas para metadados.
- **Color Theory:** Uso de superfícies escuras (Dark Mode) com pontos de acento em alta saturação.
- **Spacing:** Sistema de grid rigoroso com espaçamento generoso (Whitespace) para focar no produto.
- **Depth:** Uso de blur estratificado (Glassmorphism) e sombras de múltiplos níveis para criar hierarquia 3D.

## 3. Requisitos de Movimento (Motion Design)
Toda a experiência deve ser baseada em animações fluidas e físicas:
- **Scroll-Linked Animations:** Elementos que reagem e se transformam conforme o progresso do scroll do usuário.
- **Spring Dynamics:** Uso de física de mola para movimentos naturais, evitando transições lineares ou "artificiais".
- **Layout Transitions:** Uso de `layoutId` para transições suaves de elementos que mudam de posição ou tamanho.
- **Micro-interactions:** Feedback imediato e tátil em qualquer interação de clique, hover ou arraste.

## 4. Padrões de Código e Performance
- **Zero Bloat:** Código limpo, utilizando apenas as dependências citadas.
- **Optimization:** Carregamento inteligente de assets e otimização de renderização para garantir 60fps em animações.
- **Declarative Components:** UI separada da lógica de animação para facilitar a manutenção.

## 5. Resultado Esperado
O objetivo é uma interface disruptiva que rompa com layouts tradicionais de grid estático. Espera-se um site que:
- Cause impacto visual imediato através de movimento.
- Transmita uma sensação de produto "Premium" e "Moderno".
- Utilize tecnologias de ponta para entregar uma experiência de usuário fluida e memorável.
